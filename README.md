# 🧺 センタクびより – Weather × Life App

> 「今日は洗たくできるかな？」  
> 天気と生活をつなぐ、小さなWebアプリです。

---

![センタクびより画面イメージ](./screenshot.png)


## 🌤 概要

OpenWeather API の天気データをもとに、  
**気温・湿度・風速・降水確率** から「乾きスコア」を自動計算。  

3時間ごとの予報から最も洗たく物が乾きやすい時間帯を提案します。

👉 [デモを見る（GitHub Pages）](https://hikaru-taniguchi.github.io/sentaku-biyori/)

## 🔑 APIキー運用（サーバーレスなし版）

このアプリでは**リポジトリにAPIキーを置かない**ため、初回アクセス時にブラウザでAPIキーを入力する方式にしています。
入力したキーは `localStorage`（キー名: `openweather_api_key`）へ保存され、次回以降は再入力不要。

- APIキーを変更したい場合: ブラウザの開発者ツールで `openweather_api_key` を削除して再読み込み
- 公開デモ用の推奨: OpenWeather側で無料枠監視・定期ローテーションを実施
- 重要: フロントエンドのみ構成では「完全秘匿」ではありません（この方式は漏えいリスクを下げるための現実解です）

## 💧 乾きスコア（Dry Score）

気象庁や WeatherNews の「洗濯指数」を参考に、  
**気温・湿度・風速・降水確率** の4要素から経験式で算出。

Dry Score = 2 × 気温 + 3 × 風速 − 0.8 × 湿度 − 0.5 × 降水確率


| スコア | 状態 | コメント |
|--------|------|-----------|
| 80〜100 | ☀️ 絶好の洗たく日和 | カラッと乾きます |
| 60〜79 | 😊 よく乾きそう | 午前中がおすすめ |
| 40〜59 | 🌤 普通 | 日当たりを意識すると◎ |
| 20〜39 | ☁️ 部屋干し推奨 | 湿気多め |
| 0〜19  | ☔ 洗たくNG | 乾きにくい・雨注意 |
