# せんたくびより

天気予報から洗濯に適した時間帯を提案するWebアプリです。

## デモ

https://hikaru-taniguchi.github.io/sentaku-biyori/

## 概要

「今日はいつ洗濯をすれば乾きやすいのか？」を分かりやすく確認できるアプリです。

気温・湿度・風速・降水確率から独自スコアを算出し、洗濯に最適な時間帯を表示します。

## 開発背景

日常生活の中で、

* 天気予報を見る
* 洗濯するか判断する

という作業を毎日行っていました。

そこで、天気情報から洗濯に適したタイミングを自動で提案するアプリを作成しました。

## 使用技術

* HTML
* CSS
* JavaScript
* OpenWeather API
* GitHub Pages

## 主な機能

* 洗濯スコアの算出
* 洗濯に適した時間帯の表示
* 天気アイコン表示
* レスポンシブ対応
* デモデータ表示機能

## 工夫した点

* 気温、湿度、風速、降水確率を組み合わせた独自ロジックを実装
* API取得失敗時でもサンプルデータで動作する設計
* スマートフォンでも閲覧しやすいUIを意識

## 今後の改善予定
